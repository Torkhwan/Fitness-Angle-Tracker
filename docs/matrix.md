# matrix.py: เมทริกซ์การแปลง ดีเทอร์มิแนนต์ และเมทริกซ์ผกผัน

ภาพแต่ละภาพถ่ายใกล้-ไกล เอียง และหันซ้าย-ขวาไม่เหมือนกัน `matrix.py` สร้างเมทริกซ์ `normalization_matrix` (M) ที่ย้ายทุกภาพมาอยู่ในพิกัดมาตรฐานเดียวกัน เพื่อให้มุมที่ `angles.py` วัดได้เทียบกันได้ และหา `inverse_matrix` (M⁻¹) เพื่อแปลงเส้นท่าที่ถูกกลับไปวาดบนภาพ

ดีเทอร์มิแนนต์และเมทริกซ์ผกผันเขียนเองทั้งหมด ไม่ใช้ `np.linalg.det` และ `np.linalg.inv` (NumPy ใช้เฉพาะคูณเมทริกซ์ด้วย `@`)

## 1. พิกัดเอกพันธ์และเมทริกซ์การแปลง

การเลื่อนจุด (translation) เขียนเป็นการคูณเมทริกซ์ 2×2 ไม่ได้ จึงแทนจุด (x, y) ด้วย [x y 1]ᵀ (homogeneous coordinates) ทำให้การเลื่อน หมุน ย่อขยาย และสะท้อน เป็นเมทริกซ์ 3×3 ที่คูณรวมเป็นเมทริกซ์เดียวได้

| ฟังก์ชัน | สัญลักษณ์ | เมทริกซ์ |
|---|---|---|
| `translation(shift_x, shift_y)` | T | `[[1, 0, tx], [0, 1, ty], [0, 0, 1]]` |
| `rotation(cos_theta, sin_theta)` | R(θ) | `[[cos θ, −sin θ, 0], [sin θ, cos θ, 0], [0, 0, 1]]` |
| `scaling(scale_factor)` | S | `[[s, 0, 0], [0, s, 0], [0, 0, 1]]` (Sx = Sy = s) |
| `reflect_x()` | Fx | `[[−1, 0, 0], [0, 1, 0], [0, 0, 1]]` พลิกซ้าย-ขวา |
| `reflect_y()` | Fy | `[[1, 0, 0], [0, −1, 0], [0, 0, 1]]` พลิกบน-ล่าง |

`rotation` รับ cos θ และ sin θ โดยตรง เพราะตอนจัดท่าได้ค่าทั้งสองจากเวกเตอร์หนึ่งหน่วยของแนวพื้นอยู่แล้ว ไม่ต้องหา θ ก่อน การหมุนกลับ R(−θ) ได้จากการส่ง −sin θ เข้าไป เพราะ cos(−θ) = cos θ และ sin(−θ) = −sin θ

`apply(matrix, point)` เติม 1 ให้จุด 2 มิติเป็น [x, y, 1] คูณด้วยเมทริกซ์ แล้วคืนเฉพาะ 2 ค่าแรก

## 2. ดีเทอร์มิแนนต์: `determinant_3x3(matrix)`

กระจายโคแฟกเตอร์ตามแถวที่ 1

```
det = a(ei − fh) − b(di − fg) + c(dh − eg)      เมื่อ matrix = [[a, b, c], [d, e, f], [g, h, i]]
```

ถ้า det ≠ 0 แสดงว่าเมทริกซ์เป็น full rank และมีเมทริกซ์ผกผัน

## 3. เมทริกซ์ผกผัน: `gauss_jordan_inverse(matrix)`

ดำเนินการตามแถวบน [M | I] จนได้ [I | M⁻¹]

1. สร้างเมทริกซ์แต่งเติม `augmented` = M ต่อด้วยเมทริกซ์เอกลักษณ์ทางขวา
2. ทำทีละคอลัมน์
   1. เลือกแถวที่ค่าสัมบูรณ์ในคอลัมน์นั้นมากที่สุดเป็นตัวหลัก (partial pivoting) เพื่อลดความคลาดเคลื่อนจากการหารด้วยค่าเล็ก ๆ และรองรับกรณีตัวหลักเดิมเป็น 0
   2. ถ้าตัวหลักเล็กกว่า 10⁻¹² แปลว่าเป็นเมทริกซ์เอกฐาน แจ้ง `ValueError("Singular matrix (det = 0)")`
   3. สลับแถว แล้วหารแถวให้ตัวหลักเป็น 1
   4. กำจัดค่าในคอลัมน์เดียวกันของแถวอื่นให้เป็น 0: แถวอื่น ← แถวอื่น − (ค่าในคอลัมน์นั้น) × แถวตัวหลัก
3. ครึ่งขวาของ `augmented` คือ M⁻¹

`capture.py` ดัก `ValueError` นี้แล้วบันทึกสถานะภาพเป็น `calc_error`

## 4. เมทริกซ์จัดท่าให้เป็นมาตรฐาน

### `floor_vector(exercise, flipped_points)` เวกเตอร์แนวพื้นที่ชี้ไปทางด้านหน้าของผู้ใช้

| ท่า | เวกเตอร์แนวพื้น |
|---|---|
| `squat` | ปลายเท้า − ส้นเท้า |
| `pushup` | ข้อมือ − ปลายเท้า (ทั้งสองจุดอยู่บนพื้น) |
| `lunge` | ปลายเท้าหน้า − ส้นเท้าหน้า |

### `build_normalization_matrix(exercise, flipped_points)` คืน `(normalization_matrix, info)`

```
สูตร:   M = S · R(−θ) · Fx · T
โค้ด:   normalization_matrix = scaling_matrix @ rotation_matrix @ facing_reflection_matrix @ translation_matrix
```

การคูณเมทริกซ์ไม่มีสมบัติการสลับที่ จุดถูกคูณด้วยเมทริกซ์ขวาสุดก่อน จึงเลื่อนสะโพกไปจุดกำเนิดก่อน การหมุนและการย่อขยายจึงทำรอบสะโพก

| ลำดับ | เมทริกซ์ | ทำอะไร | วิธีหา |
|---|---|---|---|
| 1 | T (`translation_matrix`) | เลื่อนสะโพกไปที่ (0, 0) | tx = −x สะโพก, ty = −y สะโพก |
| 2 | Fx (`facing_reflection_matrix`) | ถ้าผู้ใช้หันซ้าย พลิกให้หันขวา | แนวพื้นชี้ไปทาง −x (`floor[0] < 0`) ใช้ `reflect_x()` ไม่งั้นใช้เมทริกซ์เอกลักษณ์ I |
| 3 | R(−θ) (`rotation_matrix`) | หมุนให้พื้นขนานแกน x แก้ปัญหากล้องเอียง | เวกเตอร์หนึ่งหน่วยของแนวพื้น (หลังพลิก) = f / \|f\| = (cos θ, sin θ) แล้วหมุนกลับ θ |
| 4 | S (`scaling_matrix`) | ย่อขยายให้ลำตัวยาว 1 แก้ปัญหาถ่ายใกล้-ไกลและขนาดตัว | Sx = Sy = 1 / \|ไหล่ − สะโพก\| |

`info` เก็บเมทริกซ์ทั้ง 4 ตัว แนวพื้น `floor`, `cos`, `sin`, `theta` (องศา) และความยาวลำตัว `torso` ไว้ใช้ตอนพิมพ์การคำนวณ

### ตัวอย่าง

```
พิกัดหลังกลับแกน y: ไหล่ (47, 54)  สะโพก (40, 30)  เข่า (56, 42)  ข้อเท้า (60, 20)  ส้นเท้า (59, 13)  ปลายเท้า (71, 22)

f = ปลายเท้า − ส้นเท้า = (12, 9)    |f| = 15    cos θ = 0.8    sin θ = 0.6    θ = 36.87°    f_x > 0 → Fx = I
|ไหล่ − สะโพก| = |(7, 24)| = 25    Sx = Sy = 0.04

M = [[ 0.032, 0.024, −2],        M⁻¹ = [[20, −15, 40],
     [−0.024, 0.032,  0],               [15,  20, 30],
     [ 0,     0,      1]]               [ 0,   0,  1]]

det(M) = 0.0016 = Sx · Sy       สะโพกหลังแปลง = (0, 0)       ไหล่หลังแปลง = (0.8, 0.6)
```

ถ้าผู้ใช้หันซ้าย det(M) จะติดลบ เพราะ det(Fx) = −1 แต่ไม่เป็น 0 จึงยังหาเมทริกซ์ผกผันได้

## 5. พิมพ์การคำนวณทุกขั้น: `print_explain(image_points, result)`

ใช้กับคำสั่ง `--explain` และปุ่ม `e` ในโหมดกล้อง พิมพ์ 6 หัวข้อ

1. จุดหลังกลับแกน y
2. เวกเตอร์แนวพื้น ความยาว (บอกว่าใช้ Fx หรือไม่) cos θ, sin θ และ θ
3. ความยาวลำตัว เมทริกซ์ T, Fx (เมื่อใช้), R(−θ), S, M, det(M), M⁻¹ และผลตรวจ M · M⁻¹ = I
4. จุดหลังจัดท่าให้เป็นมาตรฐาน
5. มุม 3 ค่า และค่าประกอบ เช่น ส่วนของ projection หรือค่า cross product
6. ระยะไปท่าต้นแบบแต่ละแบบ: Euclidean, Manhattan, Cosine

`format_number(value)` จัดรูปตัวเลขหรือเวกเตอร์เป็นทศนิยม 4 ตำแหน่งสำหรับการพิมพ์
