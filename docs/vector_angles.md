# vector.py และ angles.py: เวกเตอร์และมุมของแต่ละท่า

`vector.py` รวมฟังก์ชันเวกเตอร์พื้นฐาน ส่วน `angles.py` ใช้ฟังก์ชันเหล่านั้นแปลงจุดข้อต่อในพิกัดมาตรฐานให้เป็นมุม 3 ค่าต่อท่า และสร้างเส้นท่าที่ถูก ขนาดเวกเตอร์เขียนเองจากผลคูณจุด ไม่ใช้ `np.linalg.norm`

## 1. vector.py

| ฟังก์ชัน | สูตร | คืน |
|---|---|---|
| `norm(vector)` | \|v\| = √(v · v) | ขนาดของเวกเตอร์ |
| `angle_between(first_vector, second_vector)` | cos θ = (u · v) / (\|u\|\|v\|) | มุม 0–180° |
| `angle_at(center_point, first_point, second_point)` | มุมระหว่าง u = A − B และ v = C − B เมื่อ B คือข้อต่อ | มุมที่ข้อต่อ |
| `projection(vector, base_vector)` | x_u = (x · u) / (u · u), project_u x = x_u · u | (ความยาวเงา, เวกเตอร์เงา, ส่วนตั้งฉาก) |
| `cross_z(first_vector, second_vector)` | ส่วนประกอบ k ของ a × b = a₁b₂ − a₂b₁ | ค่าที่บอกทิศ |
| `euclidean(first_vector, second_vector)` | D_Euclidean = √Σ(uᵢ − vᵢ)² | ระยะ |
| `manhattan(first_vector, second_vector)` | D_Manhattan = Σ\|uᵢ − vᵢ\| | ระยะ |
| `cosine(first_vector, second_vector)` | D_Cosine = (u · v) / (\|u\|\|v\|) | ความคล้าย |
| `signed_from_vertical(vector)` | มุมจากแนวตั้ง มีเครื่องหมาย | −180° ถึง 180° |

- `vertical_unit_vector` = e₂ = (0, 1) คือ standard unit basis vector แนวตั้ง ใช้วัดว่าเวกเตอร์เอียงจากแนวตั้งกี่องศา วัดได้เพราะเมทริกซ์ M หมุนพื้นให้ขนานแกน x แล้ว
- ค่า cos ที่คำนวณได้อาจเกินช่วงเล็กน้อยจากการปัดเศษ เช่น 1.0000000002 จึงบีบให้อยู่ใน [−1, 1] ก่อนหา arccos
- `angle_at` สร้างเวกเตอร์ที่เริ่มจากข้อต่อทั้งสองตัว ถ้าลบกลับด้านจะได้มุมผิด

### มุมจากแนวตั้งที่มีเครื่องหมาย: `signed_from_vertical(vector)`

1. ฉาย `vector` ลงบน e₂ ได้ส่วนแนวตั้ง (ความยาวเงา) และส่วนตั้งฉาก (แนวนอน)
2. มุม = arccos(ส่วนแนวตั้ง / |vector|)
3. ถ้าส่วนตั้งฉากชี้ไปทาง +x (ข้างหน้า) คืนค่าบวก ไม่งั้นคืนค่าลบ

ตัวอย่าง: (1, 1) → +45°, (−1, 1) → −45° ผลคูณจุดอย่างเดียวให้มุมเป็นบวกเสมอ ส่วนตั้งฉากจาก projection จึงช่วยบอกทิศว่าเอียงไปหน้าหรือหลัง

## 2. angles.py

### เลือกขาหน้าของท่า Lunge: `prepare_points(exercise, points)`

ท่าอื่นคืนจุดเดิม ท่า Lunge ใช้ขาทั้งสองข้าง จึงต้องแยกขาหน้ากับขาหลัง

1. ทิศที่ผู้ใช้หัน = (ปลายเท้าซ้าย − ส้นเท้าซ้าย) + (ปลายเท้าขวา − ส้นเท้าขวา)
2. ถ้าค่า x ของทิศเป็นบวก ทิศ = +1 ไม่งั้น −1
3. ขาหน้าคือขาที่ข้อเท้าอยู่ไปทางทิศนั้นมากกว่า (เทียบ ทิศ × x ของข้อเท้า)
4. ตั้งชื่อจุดใหม่เป็น `front_…` และ `back_…`

### มุม 3 ค่า: `compute_angles(exercise, normalized_points)`

รับจุดในพิกัดมาตรฐาน (สะโพกที่ (0, 0), หันไปทาง +x, y ชี้ขึ้น, ลำตัวยาว 1) คืนเวกเตอร์มุม 3 ค่า และค่าประกอบสำหรับพิมพ์การคำนวณ

| ท่า | มุม | วิธีคำนวณ | ทฤษฎี |
|---|---|---|---|
| Squat | มุมเข่า | มุมที่เข่า ระหว่างเข่า→สะโพก และเข่า→ข้อเท้า | ผลคูณจุด |
| | มุมสะโพก | มุมที่สะโพก ระหว่างสะโพก→ไหล่ และสะโพก→เข่า | ผลคูณจุด |
| | มุมโน้มตัว | ฉายลำตัว (ไหล่ − สะโพก) ลงบน e₂ แล้ว arccos(ส่วนแนวตั้ง / ความยาวลำตัว) | การฉายเวกเตอร์ |
| Push-up | มุมศอก | มุมที่ศอก ระหว่างศอก→ไหล่ และศอก→ข้อมือ | ผลคูณจุด |
| | สะโพกเบี่ยง | (180° − มุมที่สะโพก) × เครื่องหมายของ cross product | ผลคูณจุด + ผลคูณไขว้ |
| | มุมลำตัวกับพื้น | มุมระหว่างเส้นไหล่−ข้อเท้า กับแกน x | ผลคูณจุด |
| Lunge | มุมเข่าหน้า | มุมที่เข่าหน้า ระหว่างเข่า→สะโพก และเข่า→ข้อเท้า | ผลคูณจุด |
| | มุมหน้าแข้ง | มุมจากแนวตั้งของ (เข่าหน้า − ข้อเท้าหน้า) มีเครื่องหมาย (+ เข่าล้ำไปข้างหน้า) | การฉายเวกเตอร์ |
| | มุมโน้มตัว | ขนาดของมุมจากแนวตั้งของ (ไหล่ − สะโพก) | การฉายเวกเตอร์ |

**สะโพกโด่งหรือตกด้วยผลคูณไขว้:** a = ไหล่ − ข้อเท้า, b = สะโพก − ข้อเท้า ถ้าส่วนประกอบ k ของ a × b เป็นบวก สะโพกอยู่เหนือเส้นไหล่-ข้อเท้า (โด่ง) ถ้าเป็นลบอยู่ใต้เส้น (ตก) ถ้าเป็น 0 ลำตัวตรง ผลคูณจุดบอกได้แค่ว่างอกี่องศา เพราะสะโพกโด่งหรือตกเท่ากันได้มุมเท่ากัน จึงต้องใช้ผลคูณไขว้บอกทิศ

```
ข้อเท้า (0, 0)  ไหล่ (10, 4)  สะโพก (5, 1)
a × b = 10(1) − 4(5) = −10 < 0 → สะโพกตก
มุมที่สะโพก: u = (5, 3), v = (−5, −1), cos θ = −28 / (√34 × √26) = −0.9418 → θ = 160.35°
สะโพกเบี่ยง = (180° − 160.35°) × (−1) = −19.65°
```

**ตัวอย่าง Squat** (พิกัดมาตรฐาน: ไหล่ (0.8, 0.6) สะโพก (0, 0) เข่า (0.8, 0) ข้อเท้า (0.4, −0.8))

```
มุมเข่า:   u = (−0.8, 0), v = (−0.4, −0.8)   cos θ = 0.32 / (0.8 × 0.8944) = 0.4472  → 63.43°
มุมสะโพก: u = (0.8, 0.6), v = (0.8, 0)      cos θ = 0.64 / (1 × 0.8) = 0.8         → 36.87°
มุมโน้ม:   t = (0.8, 0.6), t_e2 = (t · e₂) / (e₂ · e₂) = 0.6, |t| = 1   cos θ = 0.6   → 53.13°
```

### เส้นท่าที่ถูก: `ghost_segments(exercise, normalized_points, correct_template)`

คืนเส้น (จุดเริ่ม, จุดปลาย) ของท่าที่ถูกในพิกัดมาตรฐาน แล้ว `analyze.py` แปลงกลับเป็นพิกัดภาพด้วย Fy · M⁻¹ เส้นเริ่มจากข้อต่อจริงของผู้ใช้ จึงวาดทับตัวผู้ใช้พอดีทุกภาพ เวกเตอร์หนึ่งหน่วยที่เอียงจากแนวตั้งไปข้างหน้า α องศาคือ (sin α, cos α)

| ท่า | เส้นท่าที่ถูก |
|---|---|
| Squat | ลำตัวจากสะโพก เอียงตามมุมโน้มของท่าต้นแบบ correct ยาว 1 |
| Push-up | ไหล่ → สะโพกที่ถูก → ข้อเท้า โดยสะโพกที่ถูก = ข้อเท้า + project ของ (สะโพก − ข้อเท้า) ลงบนเส้นไหล่-ข้อเท้า คือจุดบนเส้นที่ใกล้สะโพกจริงที่สุด |
| Lunge | หน้าแข้งจากข้อเท้าหน้า เอียงตามมุมหน้าแข้งของท่าต้นแบบ ยาวเท่าหน้าแข้งจริง และลำตัวจากสะโพก เอียงตามมุมโน้มของท่าต้นแบบ |
