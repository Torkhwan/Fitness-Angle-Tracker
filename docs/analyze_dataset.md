# analyze.py และ dataset.py: เทียบท่าต้นแบบ สร้างท่าต้นแบบ และวัดความแม่นยำ

- `analyze.py` ต่อฟังก์ชันของ `matrix.py` และ `angles.py` เข้าด้วยกันเป็นสายเดียว: พิกัดภาพ → จัดท่าให้เป็นมาตรฐาน → มุม 3 ค่า → เทียบท่าต้นแบบ → คำแนะนำ และเส้นท่าที่ถูก
- `dataset.py` อ่านข้อมูลที่เก็บมา clean ข้อมูล ทำสถิติ สร้างท่าต้นแบบจากค่าเฉลี่ย และวัดความแม่นยำ

## 1. analyze.py

### โหลดท่าต้นแบบ: `load_templates(exercise)`

อ่านท่าต้นแบบของท่านั้นจาก `templates.json` ถ้ายังไม่มีไฟล์ จะใช้ค่าสมมติใน `config.py` แทน (ใช้ก่อนเก็บข้อมูลจริง) และคืนค่าบอกว่าใช้ค่าจากไฟล์หรือไม่

### สายการวิเคราะห์: `analyze(exercise, image_points, explain=False, templates=None)`

| ขั้น | ทำอะไร | สูตร / ฟังก์ชันที่เรียก |
|---|---|---|
| 1 | กลับแกน y ของพิกัดภาพ | P = Fy · P_img (`reflect_y`, `apply`) |
| 2 | สร้างเมทริกซ์จัดท่าให้เป็นมาตรฐาน | M = S · R(−θ) · Fx · T (`build_normalization_matrix`) |
| 3 | แปลงทุกจุดเป็นพิกัดมาตรฐาน | Q = M · P |
| 4 | คำนวณมุม 3 ค่า | x ∈ ℝ³ (`compute_angles`) |
| 5 | โหลดท่าต้นแบบ 3 แบบของท่านั้น | `load_templates` |
| 6 | วัดระยะไปท่าต้นแบบทุกแบบ แล้วเรียงตาม D_Euclidean จากน้อยไปมาก แบบแรกคือผลการตรวจ | D_Euclidean, D_Manhattan, D_Cosine |
| 7 | ผลต่างกับท่าถูกทีละมุม | d = x − t_correct |
| 8 | ผ่าน/ไม่ผ่าน และคำแนะนำ | \|dᵢ\| ≤ 10° = ผ่าน |
| 9 | หาเมทริกซ์ผกผัน | [M \| I] → [I \| M⁻¹] (`gauss_jordan_inverse`) |
| 10 | เส้นท่าที่ถูกแปลงกลับลงภาพ | P_img = Fy · M⁻¹ · Q (`ghost_segments`) |
| 11 | รวมผลทั้งหมดเป็น `result` ส่งให้ `capture.py` วาดและแสดง | |

**ขั้น 6 เลือกท่าต้นแบบที่ใกล้ที่สุด:** ตัดสินด้วย D_Euclidean เพราะมุมมีหน่วยเป็นองศาและขนาดของมุมมีความหมาย ส่วน D_Manhattan และ D_Cosine คำนวณไว้แสดงเปรียบเทียบ (D_Cosine ดูแค่ทิศของเวกเตอร์ เช่น (60, 30, 15) กับ (120, 60, 30) ได้ค่า 1 ทั้งที่เป็นท่าต่างกันมาก)

```
x = (63.43, 36.87, 53.13)
correct       t = (76.49, 72.29, 27.56)     D_Euclidean = √(170.56 + 1254.58 + 653.82) = 45.60
lean_forward  t = (76.65, 51.46, 42.13)     D_Euclidean = √(174.77 + 212.87 + 121.00) = 22.55   ← น้อยที่สุด
shallow       t = (103.03, 103.25, 20.10)   D_Euclidean = √(1568.16 + 4406.30 + 1090.98) = 84.06
→ ผลการตรวจ: lean_forward (หลังโน้มไปข้างหน้ามากเกินไป)
```

**ขั้น 7–8 คำแนะนำ:** เทียบกับท่าถูกเพียงแบบเดียวทีละมุม มุมที่ต่างเกิน ±10° (`TOLERANCE` ใน `config.py`) แสดงว่าไม่ผ่าน และถ้ามุมนั้นมีข้อความแก้ท่าใน `config.py` จะได้คำแนะนำพร้อมจำนวนองศา บางมุมไม่มีข้อความ เช่น มุมสะโพกของ Squat จึงขึ้นแค่ไม่ผ่าน ผลการตรวจ (ขั้น 6) กับคำแนะนำ (ขั้น 8) แยกกัน จึงอาจทายว่าเป็นท่าถูก แต่ยังมีมุมที่ควรปรับได้

```
d = (63.43, 36.87, 53.13) − (76.49, 72.29, 27.56) = (−13.06, −35.42, +25.57)
มุมโน้มตัว +25.57° > 10° → "ลำตัวโน้มไปข้างหน้ามากเกินไป 26° → ยืดอก ดันสะโพกไปด้านหลัง"
```

**ขั้น 10 แปลงกลับ:** เส้นท่าที่ถูกคำนวณในพิกัดมาตรฐาน คูณด้วย M⁻¹ เพื่อย้อนการจัดท่า แล้วคูณด้วย Fy เพื่อกลับแกน y เป็นพิกัดภาพ ใช้ Fy ตัวเดิมได้เพราะ Fy · Fy = I

### สรุปผล: `print_result(result)`

พิมพ์มุม 3 ค่า แบบที่ใกล้ที่สุด (ภาษาไทย) ผลต่างจากท่าถูกพร้อมผ่าน/ไม่ผ่านทีละมุม และคำแนะนำ

## 2. dataset.py

### อ่านและ clean ข้อมูล: `load_dataset(paths)`

อ่านไฟล์ `data_<ท่า>.csv` ทีละแถว

1. **ตัดข้อมูลซ้ำ:** ถ้าพิกัด 66 ค่าเหมือนกับแถวใดแถวหนึ่งที่อ่านมาแล้วทุกตัว แปลว่าบันทึกภาพเดียวกันซ้ำ (เช่น กดบันทึกเฟรมเดียวกัน 2 ครั้ง) จึงข้ามแถวนั้น
2. **สมบูรณ์ / ต้องตรวจ:** ถ้า visibility ของข้อต่อหลักของท่านั้นไม่ต่ำกว่า 0.5 ทุกจุด นับเป็นสมบูรณ์ ถ้ามีบางจุดต่ำกว่า นับเป็นต้องตรวจ (เปิดภาพผลลัพธ์ตรวจด้วยตา) ทั้งสองแบบยังใช้ต่อ
3. **เมทริกซ์ข้อมูล:** มุม 3 ค่าของแต่ละภาพเรียงเป็นแถวของเมทริกซ์ X ขนาด n × 3 แยกตามท่าและแบบ

`count_discarded(exercise)` นับภาพที่ถูกตัดทิ้งตั้งแต่ตอนเก็บข้อมูล (ไม่พบคน เห็นข้อต่อไม่ชัด ฯลฯ) จาก `clean_log.csv` และ `percent(part, whole)` หาร้อยละ

### สถิติและท่าต้นแบบ: `build_templates(paths)`

1. **สถิติการ clean:** จำนวนก่อนและหลัง clean และสัดส่วนข้อมูลสมบูรณ์ / ต้องแก้ไข / ตัดทิ้ง

```
ก่อน clean = แถวใน CSV + ภาพที่ตัดทิ้งตอนเก็บข้อมูล
ตัดทิ้ง     = ภาพที่ตัดทิ้งตอนเก็บข้อมูล + แถวซ้ำ
สัดส่วน (%) = จำนวน / ก่อน clean × 100
```

2. **สถิติของแต่ละแบบ:** จำนวน, ร้อยละ, ค่าเฉลี่ย, ส่วนเบี่ยงเบนมาตรฐานของประชากร σ = √(Σ(xᵢ − x̄)² / n), ค่าต่ำสุด และค่าสูงสุด ของทุกมุม

3. **ท่าต้นแบบ:** เวกเตอร์ค่าเฉลี่ยของแถวทั้งหมดในเมทริกซ์ X

```
t = (1/n) Σ xᵢ     ในโค้ด: X.mean(axis=0)  (ค่าเฉลี่ยทีละคอลัมน์ = ค่าเฉลี่ยของเวกเตอร์)

ตัวอย่าง pushup_shallow (n = 40):  Σ = (5408.292, −122.573, 565.944)
t = (5408.292, −122.573, 565.944) / 40 = (135.21, −3.06, 14.15)
```

ค่าเฉลี่ยเป็นตัวแทนของทั้งกลุ่ม และเป็นจุดที่ผลรวมระยะ Euclidean กำลังสองถึงทุกภาพในกลุ่มน้อยที่สุด จึงเหมาะกับการเลือกแบบด้วยระยะ Euclidean ท่าต้นแบบทั้ง 9 แบบบันทึกลง `templates.json`

### วัดความแม่นยำ: `evaluate(paths, test_ratio=0.2, seed=0)`

ทุกภาพที่ทดสอบ เลือกท่าต้นแบบที่ D_Euclidean น้อยที่สุด แล้วนับลง confusion matrix C (แถว = แบบจริง, คอลัมน์ = แบบที่ระบบทาย)

```
ความแม่นยำ = trace(C) / ผลรวมของ C      (ผลรวมเส้นทแยงหลัก = จำนวนที่ทายถูก)
```

| `test_ratio` | วิธีทดสอบ |
|---|---|
| `0` | ใช้ท่าต้นแบบจริงจาก `templates.json` ทายข้อมูลทุกแถว (ค่าที่ใช้ในรายงาน) |
| ค่าอื่น เช่น `0.2` (ค่าเริ่มต้น) | สุ่มแบ่งข้อมูลแต่ละแบบ (seed = 0) ใช้ 80% หาค่าเฉลี่ย แล้วทาย 20% ที่เหลือซึ่งระบบไม่เคยเห็น |

ผลกับข้อมูล 360 ภาพ (`--test-ratio 0`)

| ท่า | confusion matrix | ความแม่นยำ |
|---|---|---|
| Squat (correct, lean_forward, shallow) | [[30, 7, 3], [7, 33, 0], [0, 0, 40]] | 103/120 = 85.8% |
| Push-up (correct, shallow, hip_sag) | [[35, 1, 4], [0, 39, 1], [1, 1, 38]] | 112/120 = 93.3% |
| Lunge (correct, knee_over_toe, torso_lean) | [[22, 14, 4], [3, 37, 0], [2, 0, 38]] | 97/120 = 80.8% |
| **รวม** | | **312/360 = 86.7%** |

ภาพที่ใช้ทดสอบเป็นชุดเดียวกับที่ใช้หาค่าเฉลี่ย ความแม่นยำกับภาพใหม่ที่ระบบไม่เคยเห็นจึงอาจต่ำกว่านี้
