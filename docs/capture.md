# capture.py และ pose_coach.py: รับภาพ หาพิกัดข้อต่อ บันทึกข้อมูล และแสดงผล

ส่วนที่ติดต่อกับผู้ใช้และภาพ: เปิดภาพหรือกล้อง ให้ MediaPipe หาพิกัดข้อต่อ ส่งให้ `analyze` วิเคราะห์ แล้ววาดผลลงภาพ และบันทึกข้อมูลลง CSV ตอนเก็บข้อมูล ส่วนนี้ไม่มีการคำนวณทางทฤษฎี ใช้ OpenCV อ่านภาพ แปลงสี วาดเส้นและข้อความ และแสดงหน้าต่าง ส่วน MediaPipe ใช้เพียงหาพิกัดข้อต่อ

## 1. capture.py

### เตรียมโมเดล: `make_landmarker(video=False)`

ถ้ายังไม่มีไฟล์โมเดล `pose_landmarker_full.task` จะดาวน์โหลดให้อัตโนมัติ แล้วสร้าง Pose Landmarker โหมดภาพนิ่งหรือวิดีโอ ตรวจหาคนเดียวต่อภาพ โปรแกรมอ่านไฟล์โมเดลเป็นข้อมูลก่อนส่งให้ MediaPipe เพื่อให้ใช้ได้แม้โฟลเดอร์มีชื่อภาษาไทย

### ดึงพิกัดและเลือกข้าง: `extract(exercise, detection, width, height)`

1. ถ้า MediaPipe ไม่พบคน คืนสถานะ `no_person`
2. MediaPipe คืนพิกัด (x, y) เป็นสัดส่วน 0–1 ของภาพ และค่า visibility ของทั้ง 33 จุด แปลงเป็นพิกเซลด้วย x × ความกว้าง และ y × ความสูง
3. **เลือกข้าง:** หาค่าเฉลี่ย visibility ของข้อต่อหลักของท่านั้นทั้งข้างซ้ายและขวา เลือกข้างที่มากกว่า เพราะเป็นข้างที่หันเข้าหากล้อง
4. ถ้าค่าเฉลี่ยของข้างที่เลือกต่ำกว่า 0.5 คืนสถานะ `low_visibility`
5. Squat และ Push-up ใช้จุดของข้างที่เลือก Lunge ใช้ไหล่และสะโพกของข้างที่เลือก กับเข่า ข้อเท้า ส้นเท้า ปลายเท้าของขาทั้งสองข้าง แล้วแยกขาหน้าด้วย `prepare_points`

ตัวอย่าง (ภาพ squat_lean_forward_jennie_01.png): ค่าเฉลี่ย visibility ข้างซ้าย 0.9882 ข้างขวา 0.6114 → ใช้ข้างซ้าย

### บันทึกข้อมูล: `save_row(...)` และ `log_clean(...)`

- `save_row` ต่อท้าย 1 แถวต่อ 1 ภาพใน `data_<ท่า>.csv`: เวลา ท่า แบบ ข้างที่ใช้ มุม 3 ค่า พิกัด 66 ค่า และ visibility 33 ค่า รวม 106 คอลัมน์ บันทึกพิกัดแบบดิบจาก MediaPipe ไว้ด้วย เพื่อใช้ตรวจข้อมูลซ้ำ ตรวจ visibility และคำนวณใหม่ได้โดยไม่ต้องเปิดภาพ
- `log_clean` บันทึกทุกภาพที่ป้อนตอนเก็บข้อมูลลง `clean_log.csv` ว่าใช้ได้หรือถูกตัดเพราะอะไร ใช้นับตาราง clean ในรายงาน

### วาดผล: `draw(image, points, result)`

| สิ่งที่วาด | ที่มา |
|---|---|
| เส้นโครงร่าง สีเขียวเมื่อระบบทายว่าท่าถูก สีแดงเมื่อทายว่าท่าผิด | พิกัดข้อต่อจริง ลากตามคู่จุดใน `config.py` สีจากผลการตรวจ `ranking[0]` |
| จุดข้อต่อสีขาว | พิกัดข้อต่อจริง |
| เส้นท่าที่ถูกสีเหลือง | `ghosts` ที่ `analyze.py` แปลงกลับด้วย Fy · M⁻¹ แล้ว |
| ข้อความมุมซ้ายบน: มุม 3 ค่า, แบบที่ใกล้ที่สุดและระยะ Euclidean, `yellow = correct form` | `result` จาก `analyze` |

ข้อความเขียนสองชั้น (ขอบดำหนา แล้วทับด้วยสีหลักบาง) ให้อ่านง่ายบนทุกพื้นหลัง ข้อความบนภาพเป็นภาษาอังกฤษเพราะ OpenCV แสดงภาษาไทยไม่ได้

### ตรวจภาพ: `run_image(...)` และ `run_folder(...)`

`run_image` อ่านภาพ แปลงสี BGR เป็น RGB ให้ MediaPipe หาพิกัด เรียก `analyze` พิมพ์ผล บันทึกข้อมูล (เมื่อระบุ `--label`) และบันทึกภาพผลลัพธ์ `<ชื่อเดิม>_result.jpg` ถ้าคำนวณไม่ได้ เช่น แนวพื้นยาว 0 หรือหาเมทริกซ์ผกผันไม่ได้ จะบันทึกสถานะ `calc_error` แล้วทำภาพถัดไปต่อ

`run_folder` สร้าง landmarker ครั้งเดียวแล้วตรวจทุกภาพในโฟลเดอร์ เก็บภาพผลลัพธ์ใน `<โฟลเดอร์>/results` และสรุปว่าใช้ได้กี่ภาพ ใช้ไม่ได้เพราะอะไรกี่ภาพ

### โหมดกล้อง: `run_camera(exercise, camera_index, save)`

ตรวจทุกเฟรมจากกล้อง หน้าต่างชื่อ `FAT Pose Coach - <ท่า>` ลากขยายได้ และมีไอคอน FAT (`set_window_icon`) ประเมินท่าเฉพาะตอนลงท่าแล้ว (`gate` ใน `config.py` เช่น Squat มุมเข่าต่ำกว่า 130°) และแสดงชื่อท่ามุมขวาล่าง

| ปุ่ม | ทำอะไร |
|---|---|
| `s` `p` `l` | สลับท่าเป็น squat / pushup / lunge (`camera_mode` เปลี่ยนชื่อหน้าต่างและความหมายของปุ่ม 1 2 3 ตามท่า) |
| `e` | พิมพ์การคำนวณทุกขั้นของเฟรมล่าสุด |
| `1` `2` `3` | บันทึกเฟรมล่าสุดลง CSV ตามแบบของท่าปัจจุบัน |
| `q` | ปิดกล้อง |

## 2. pose_coach.py

รับคำสั่งจากผู้ใช้แล้วเรียกฟังก์ชันที่ตรงกัน

| argument | ทำอะไร |
|---|---|
| `--exercise` | ท่า `squat` / `pushup` / `lunge` (ค่าเริ่มต้น `squat`) |
| `--image` | ไฟล์ภาพหรือโฟลเดอร์ภาพ |
| `--camera` | หมายเลขกล้อง (0, 1, 2, …) |
| `--explain` | พิมพ์การคำนวณทุกขั้น |
| `--label` | แบบของภาพตอนเก็บข้อมูล ถ้าระบุจะบันทึกลง CSV |
| `--save` | ชื่อไฟล์ CSV (ค่าเริ่มต้น `data_<ท่า>.csv`) |
| `--build-templates` | สถิติและสร้างท่าต้นแบบจาก CSV |
| `--evaluate` | วัดความแม่นยำจาก CSV |
| `--test-ratio` | สัดส่วนข้อมูลทดสอบ (ค่าเริ่มต้น 0.2, 0 = ใช้ท่าต้นแบบจริงทายทุกแถว) |
| `--selftest` | ชุดทดสอบทั้งระบบ |

ไม่ใส่ argument จะแสดงรายการคำสั่งทั้งหมด
