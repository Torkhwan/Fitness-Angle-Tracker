# FAT: Fitness Angle Tracker

ระบบตรวจสอบความถูกต้องของท่าออกกำลังกายโดยทฤษฎีเวกเตอร์และเมทริกซ์

โครงงานวิชา ELEMENTARY DIFFERENTIAL EQUATIONS AND LINEAR ALGEBRA ปีการศึกษา 2569 กลุ่มแมวส้ม & โอริโอ้

FAT รับภาพของผู้ฝึกที่ถ่ายจากด้านข้างขณะทำท่า Squat, Push-up หรือ Lunge แล้วบอกว่าท่านั้นถูกหรือผิด ผิดแบบใด ผิดที่ข้อต่อไหน ต่างจากท่าที่ถูกกี่องศา พร้อมวาดเส้นท่าที่ถูกต้องทับบนภาพ MediaPipe ใช้เพียงหาพิกัดข้อต่อจากภาพ ส่วนการวิเคราะห์ทั้งหมดเขียนขึ้นเองด้วยทฤษฎีเวกเตอร์และเมทริกซ์

## ที่มาและความสำคัญ

คนไทยออกกำลังกายมากขึ้น สัดส่วนของผู้ที่มีอายุมากกว่า 15 ปีที่ออกกำลังกายมากกว่า 3 วันต่อสัปดาห์เพิ่มจากร้อยละ 40.4 ในปี 2565 เป็นร้อยละ 44.4 ในปี 2567 แต่ไม่ใช่ทุกคนที่ฝึกภายใต้การดูแลของผู้เชี่ยวชาญ ผู้ออกกำลังกายราว 4 ใน 10 ฝึกด้วยตนเองที่บ้านหรือในที่สาธารณะ และผู้ที่ใช้บริการฟิตเนสก็ไม่ได้มีเทรนเนอร์ส่วนตัวทุกคน ([ศูนย์วิจัยกสิกรไทย](https://www.kasikornresearch.com/th/analysis/k-social-media/Pages/Fitness-Gym-Revenue-CIS3593-FB-2025-07-31.aspx))

การฝึกด้วยตนเองมักทำตามคลิปวิดีโอ ผู้ฝึกมองไม่เห็นท่าของตัวเองจากด้านข้าง จึงไม่รู้ว่าทำถูกหรือไม่ เช่น สควอตแล้วโน้มลำตัวมากเกินไปหรือย่อไม่ลึกพอ วิดพื้นแล้วงอศอกไม่พอหรือปล่อยให้สะโพกตก ลันจ์แล้วเข่าล้ำปลายเท้า การทำท่าผิดซ้ำ ๆ ทำให้กล้ามเนื้อที่ต้องการฝึกทำงานไม่เต็มที่ และทำให้แรงไปกดที่หลังส่วนล่าง เข่า หรือหัวไหล่ เสี่ยงต่อการบาดเจ็บ

คลิปสอนแสดงได้เพียงท่าที่ถูก แต่บอกไม่ได้ว่าท่าของผู้ฝึกต่างจากท่าที่ถูกตรงไหนและเท่าไร ความผิดพลาดเหล่านี้เป็นเรื่องของมุมข้อต่อที่ต่างกันเพียง 10–20 องศา ซึ่งดูด้วยตาเปล่าได้ยาก แต่วัดได้ด้วยคณิตศาสตร์

## แนวคิดการพัฒนา

- **เปลี่ยนท่าทางให้เป็นตัวเลข:** พิกัดข้อต่อจากภาพถูกแปลงเป็นเวกเตอร์ แล้วคำนวณเป็นมุม 3 ค่าต่อท่า ภาพหนึ่งภาพจึงแทนด้วยเวกเตอร์มุม x ∈ ℝ³
- **ไม่ขึ้นกับมุมกล้อง:** ภาพแต่ละภาพถ่ายจากระยะ มุมเอียง และทิศที่หันต่างกัน ระบบจึงจัดท่าให้เป็นมาตรฐานด้วยเมทริกซ์ M = S · R(−θ) · Fx · T ก่อนวัดมุม ทำให้ท่าเดียวกันได้มุมเท่ากันเสมอ
- **เกณฑ์มาจากข้อมูลจริง:** ไม่ตั้งเกณฑ์มุมขึ้นเอง ท่าต้นแบบของแต่ละแบบคือค่าเฉลี่ยของเวกเตอร์มุมจากภาพจริง ท่าถูกมาจากภาพเทรนเนอร์ ท่าผิดมาจากภาพที่สมาชิกทำท่าผิดจริง
- **บอกได้ว่าผิดแบบใด:** เลือกท่าต้นแบบที่ใกล้ที่สุดด้วยระยะ Euclidean แล้วเทียบกับท่าถูกทีละมุม บอกจำนวนองศาที่ต้องแก้
- **เห็นท่าที่ถูกบนภาพตัวเอง:** ใช้เมทริกซ์ผกผัน M⁻¹ แปลงเส้นท่าที่ถูกกลับไปวาดทับบนภาพของผู้ใช้
- **ตรวจสอบได้ทุกขั้น:** สูตรทุกตัว เช่น ขนาดเวกเตอร์ ดีเทอร์มิแนนต์ เมทริกซ์ผกผัน เขียนเองโดยไม่ใช้ฟังก์ชันสำเร็จรูป และโปรแกรมพิมพ์การคำนวณทุกขั้นออกมาให้ตรวจได้

## ขั้นตอนการทำงาน

```
ภาพด้านข้าง → พิกัดข้อต่อ 33 จุด → จัดท่าด้วยเมทริกซ์ M → มุม 3 ค่า → เทียบท่าต้นแบบ → ผลการตรวจ + คำแนะนำ + เส้นท่าที่ถูก
               (MediaPipe)          Q = M · Fy · P         (เวกเตอร์)    (Euclidean)        (วาดกลับด้วย Fy · M⁻¹)
```

1. MediaPipe Pose Landmarker หาพิกัดข้อต่อ 33 จุด ระบบเลือกด้านของร่างกายที่เห็นชัดกว่าจากค่า visibility
2. กลับแกน y ของพิกัดภาพด้วยเมทริกซ์สะท้อน Fy
3. สร้างเมทริกซ์ M เลื่อนสะโพกไปจุดกำเนิด (T) พลิกให้หันขวา (Fx) หมุนพื้นให้ขนานแกน x (R(−θ)) และย่อขยายให้ลำตัวยาว 1 (S)
4. คำนวณมุม 3 ค่าของท่านั้นด้วยผลคูณจุด การฉายเวกเตอร์ และผลคูณไขว้
5. วัดระยะ Euclidean ไปยังท่าต้นแบบทั้ง 3 แบบของท่านั้น แบบที่ใกล้ที่สุดคือผลการตรวจ
6. เทียบกับท่าถูกทีละมุม มุมที่ต่างเกิน ±10° แสดงว่าไม่ผ่าน และได้คำแนะนำวิธีแก้
7. หา M⁻¹ ด้วย Gauss-Jordan แล้ววาดเส้นท่าที่ถูกกลับลงบนภาพ

## ทฤษฎีที่ใช้

| ทฤษฎี | ใช้ทำอะไร |
|---|---|
| พิกัดเอกพันธ์และเมทริกซ์การแปลง (Translation, Rotation, Scaling, Reflection) | จัดท่าให้เป็นมาตรฐาน M = S · R(−θ) · Fx · T |
| ดีเทอร์มิแนนต์ (cofactor expansion) | ตรวจว่า M มีเมทริกซ์ผกผัน |
| เมทริกซ์ผกผันด้วย Gauss-Jordan [M \| I] → [I \| M⁻¹] | แปลงเส้นท่าที่ถูกกลับลงภาพ |
| ขนาดเวกเตอร์และเวกเตอร์หนึ่งหน่วย | แนวพื้น ความยาวลำตัว |
| ผลคูณจุด cos θ = (u · v) / (\|u\|\|v\|) | มุมเข่า สะโพก ศอก และมุมลำตัวกับพื้น |
| การฉายเวกเตอร์ x_u = (x · u) / (u · u) | มุมโน้มตัว มุมหน้าแข้ง และตำแหน่งสะโพกที่ถูก |
| ผลคูณไขว้ (ส่วนประกอบ k) | บอกว่าสะโพกโด่งหรือตกในท่าวิดพื้น |
| D_Euclidean, D_Manhattan, D_Cosine | เลือกท่าต้นแบบที่ใกล้ที่สุด |
| ค่าเฉลี่ยของเวกเตอร์ t = (1/n) Σ xᵢ | สร้างท่าต้นแบบจากเมทริกซ์ข้อมูล X (n × 3) |

## ท่าและมุมที่ตรวจ

| ท่า | มุม 3 ค่า | แบบที่ตรวจได้ |
|---|---|---|
| Squat | มุมเข่า, มุมสะโพก, มุมโน้มตัว | ท่าถูก, หลังโน้มมาก, ย่อไม่พอ |
| Push-up | มุมศอก, สะโพกเบี่ยงจากแนวลำตัว, มุมลำตัวกับพื้น | ท่าถูก, งอศอกไม่พอ, สะโพกตก |
| Lunge | มุมเข่าหน้า, มุมหน้าแข้งหน้า, มุมโน้มตัว | ท่าถูก, เข่าล้ำปลายเท้า, ลำตัวโน้ม |

## ข้อมูลและผลลัพธ์

- **ข้อมูล:** 9 กลุ่ม (3 ท่า × 3 แบบ) กลุ่มละ 40 ภาพ รวม 360 ชุด ท่าถูกมาจากภาพเทรนเนอร์ (YouTube, เว็บไซต์, Kaggle) และ Squat Dataset (Teng, 2025, Zenodo, CC BY 4.0) ท่าผิดมาจากภาพที่สมาชิกถ่ายเอง
- **การ Clean:** เก็บภาพ 574 ภาพ คัดออก 214 ภาพที่ไม่แสดงลักษณะท่าผิดของกลุ่ม ผิดหลายจุด เป็นท่าเตรียม หรือโครงร่างไม่ทับตัวคน
- **ความแม่นยำ:** ใช้ท่าต้นแบบของโปรแกรมทายภาพทั้ง 360 ภาพ ได้ Squat 85.8%, Push-up 93.3%, Lunge 80.8% รวม 86.7% (312/360) ภาพที่ใช้ทดสอบเป็นชุดเดียวกับที่ใช้หาค่าเฉลี่ย ความแม่นยำกับภาพใหม่จึงอาจต่ำกว่านี้

ข้อมูลมุมและพิกัดอยู่ใน `posecoach/data_squat.csv`, `data_pushup.csv`, `data_lunge.csv` และท่าต้นแบบอยู่ใน `posecoach/templates.json` ส่วนภาพถ่ายไม่ได้อัปโหลดขึ้น GitHub เพราะเป็นภาพบุคคล

## การติดตั้งและใช้งาน

ใช้ Python 3.10 ขึ้นไป

```bash
pip install -r requirements.txt
```

```bash
cd posecoach
```

| ใช้ทำอะไร | คำสั่ง |
|---|---|
| ทดสอบการคำนวณทั้งระบบ | `python pose_coach.py --selftest` |
| ตรวจภาพ 1 ภาพ พร้อมแสดงการคำนวณทุกขั้น | `python pose_coach.py --exercise squat --image <ไฟล์ภาพ> --explain` |
| ตรวจทุกภาพในโฟลเดอร์ (ผลลัพธ์อยู่ใน `<โฟลเดอร์>/results`) | `python pose_coach.py --exercise pushup --image <โฟลเดอร์>` |
| ตรวจจากกล้อง | `python pose_coach.py --exercise lunge --camera 0` |
| สถิติและสร้างท่าต้นแบบ | `python pose_coach.py --build-templates data_squat.csv data_pushup.csv data_lunge.csv` |
| วัดความแม่นยำด้วยท่าต้นแบบจริง | `python pose_coach.py --evaluate data_squat.csv data_pushup.csv data_lunge.csv --test-ratio 0` |

ครั้งแรกที่รัน โปรแกรมจะดาวน์โหลดโมเดล MediaPipe (`pose_landmarker_full.task`) ให้เอง รัน `python pose_coach.py` เฉย ๆ จะแสดงรายการคำสั่งทั้งหมด

ภาพที่ใช้ได้ดีที่สุด: ถ่ายจากด้านข้าง เห็นทั้งตัวตั้งแต่ศีรษะถึงปลายเท้า มีคนเดียวในภาพ และถ่ายตอนลงท่าต่ำสุด

**ปุ่มในหน้าต่างกล้อง** (คลิกที่หน้าต่างภาพและเปลี่ยนแป้นพิมพ์เป็นภาษาอังกฤษก่อน)

| ปุ่ม | ทำอะไร |
|---|---|
| `s` `p` `l` | สลับท่าเป็น squat / pushup / lunge |
| `e` | แสดงการคำนวณของเฟรมล่าสุดใน terminal |
| `1` `2` `3` | บันทึกเฟรมล่าสุดลง CSV ตามกลุ่มของท่าปัจจุบัน (ใช้ตอนเก็บข้อมูล) |
| `q` | ปิดกล้อง |

**การอ่านผลบนภาพ:** เส้นสีเขียวคือระบบทายว่าท่าถูก เส้นสีแดงคือท่าผิด เส้นสีเหลืองคือแนวท่าที่ถูกต้อง มุมซ้ายบนแสดงมุม 3 ค่า แบบที่ใกล้ที่สุด และระยะ Euclidean
